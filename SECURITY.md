# Security Policy

## Reporting a vulnerability

When this project is hosted on GitHub and private vulnerability reporting is available, use that channel for security reports. Until then, do not disclose sensitive details in a public issue; contact the maintainer through the hosting channel described by the project instead.

Reports should explain the affected version or commit, impact, and a minimal safe reproduction. Do not include real resumes, contact information, credentials, access tokens, or other personal data in an issue, report, reproduction, log, or attachment. Use synthetic or fully redacted material.

## Scope

This project is a local, portable skill source at version 0.1.0. It has no created or verified remote repository, hosted service, or release channel. Reports about the skill's instructions, repository scripts, and GitHub workflow configuration are in scope when a hosting channel becomes available.
